🐙 GitHub Card Generator (gitthub)
A simple and stylish GitHub Profile Card Generator built using HTML, CSS, and JavaScript.
This app allows users to enter a GitHub username and fetch their profile details using the GitHub API, then display the data in a clean UI card.

✨ Features
🔍 Search GitHub users by username
👤 Display profile details like:

Name
Avatar
Bio
Followers & Following

Public Repositories
⚡ Real-time API Fetch
🎨 Beautiful card UI
📱 Fully responsive
🚀 Fast and lightweight

🛠️ Technologies Used
